Masalah terbesarnya bukan karena materi mereka jelek, melainkan karena **tidak pernah mendapatkan feedback terukur dan objektif** sebelum tampil.*  
>  
> *Perkenalkan **VOIC — Voice & Optics Intelligent Coach**. Sebuah platform web cerdas yang menggabungkan analisis tatapan mata (optics), ekspresi wajah (facial composure), serta tempo vokal secara real-time langsung melalui browser laptop tanpa perlu server mahal.*  
>  
> *Dengan VOIC, pengguna cukup menyalakan webcam, memilih skenario latihan, dan dalam hitungan menit mendapatkan laporan evaluasi, grafik skor perkembangan, serta saran actionable untuk tampil percaya diri maksimal di hadapan audiens!"*

## 2. Alur Demo Interaktif di Booth (3-Minute Live Demo Script)

Gunakan skenario ini saat juri atau pengunjung mendatangi booth pameran:

### Menit 1: Landing Page & Akses Cepat (1-Click Demo)
1. Tunjukkan halaman **Landing Page** yang modern dan profesional.
2. Jelaskan fitur **Quick Login Akun Demo** (`test@example.com` / `password`) sehingga pengunjung tidak perlu repot mengetik data.
3. Masuk ke **Dashboard Analisis**.

### Menit 2: Dashboard & Metrik Awal
1. Perlihatkan **4 Stat Cards**: Rata-rata Skor, Skor Tertinggi, Total Latihan, dan Total Waktu Bicara.
2. Tunjukkan **Grafik Tren Performa (Chart.js)**: Jelaskan bagaimana sistem mencatat peningkatan skor dari sesi ke sesi sebagai bukti efektivitas latihan.

### Menit 3: Live Practice Mode & Evaluasi Instan (Fitur Paling Menjual!)
1. Buka menu **Mulai Latihan AI** (`/practice`).
2. Pilih skenario **"Pitching Startup"** atau **"Sidang Skripsi"**.
3. Nyalakan kamera dan mikrofon:
   - Tunjukkan **Live Volume Visualizer** saat Anda berbicara (bar audio bergerak naik-turun).
   - Tunjukkan **Deteksi Fokus Tatapan** dan **Deteksi Ekspresi/Senyum**.
   - Perlihatkan live **WPM (Words Per Minute)**.
4. Klik **"Selesai & Analisis AI"**.
5. Muncul **Laporan Evaluasi Performa** dengan Skor Dial, 4 Parameter Grafis, serta Saran Evaluasi AI.
6. Tekan tombol **Cetak / Simpan PDF** untuk menunjukkan bahwa laporan bisa diarsipkan atau diserahkan ke dosen pembimbing / mentor.

## 3. Keunggulan Kompetitif (Competitive Advantages)

| Aspek | Aplikasi Pelatihan Konvensional | VOIC (Voice & Optics Intelligent Coach) |
|---|---|---|
| **Evaluasi** | Subjektif (tergantung perasaan pelatih) | Objektif & terukur (berbasis angka, persen, dan WPM) |
| **Kebutuhan Perangkat** | Membutuhkan sensor/kamera khusus | Cukup webcam & mikrofon bawaan laptop via browser |

| **Riwayat Belajar** | Manual / catatan kertas | Database terstruktur MySQL dengan visualisasi grafik tren |

## 4. Antisipasi Pertanyaan Juri (Q&A Handling)

**Q1: Bagaimana cara kerja analisis wajah dan suara tanpa server GPU mahal?**  
> **Jawaban:** *VOIC memanfaatkan komputasi tepi (Edge / Client-Side Computing) menggunakan Web Audio API dan Canvas Telemetry di peramban pengguna. Hal ini menghasilkan latensi nol, menghemat biaya server 100%, serta menjamin privasi rekaman pengguna tidak bocor ke internet.*

**Q2: Bagaimana penentuan skor keseluruhan dihitung?**  
> **Jawaban:** *Skor dihitung menggunakan formula berbobot ilmiah: 35% stabilitas tatapan kontak mata, 35% relaksasi ekspresi wajah, dan 30% ketepatan tempo bicara (WPM ideal 120-150 kata per menit).*

**Q3: Apa rencana pengembangan ke depan setelah Innofest?**  
> **Jawaban:** *Kami berencana menambahkan Speech-to-Text berbasis AI lokal untuk mendeteksi filler words (seperti "ehm", "anu", "ngg") serta fitur sertifikasi otomatis untuk lembaga kampus.*
